# GlowFX Installer

One-click installer for GlowFX Photoshop plugins. Tick the plugins you want, click **Install**, and they show up in Photoshop.

**[⬇ Download GlowFX Installer (Windows)](https://github.com/Mouadgrna/GlowFX-Installer/raw/main/installer/GlowFXInstaller.exe)**

![GlowFX Installer](app/app-icon-256.png)

## For users
1. Download `GlowFXInstaller.exe` with the link above and run it. You don't need to install anything else.
   - Windows may show *"Windows protected your PC"* the first time, because the app isn't code-signed. Click **More info → Run anyway**.
2. Tick the plugins you want and click **Install**.
3. Open Photoshop and go to **Plugins** → the plugin's name.

Updates show up as **Update available** the next time you open the app, already ticked, so you only have to click **Update**. The app also updates itself.

Requirements: Windows 10/11, Photoshop 2024 or newer, and the Creative Cloud desktop app (it does the actual install).

## For the publisher: pushing an update

1. Change the plugin, then **bump `version`** in its `manifest.json` (for example `1.2.1` → `1.2.2`).
2. From this folder, run:
   ```
   node publish/publish.js --push -m "Holo Glow 1.2.2: what changed"
   ```
   This packages every plugin in `publish/plugins.json`, writes `catalog.json`, and pushes to GitHub.
3. That's it. Everyone sees **Update available** the next time they open the installer. GitHub can take up to about 5 minutes to serve the new catalog.

The script warns you if a plugin's files changed but you forgot to bump its version.

### Adding a new plugin
Add an entry to `publish/plugins.json`:
```json
{
  "folder": "myeffect",
  "source": "../../MyEffect",
  "icon": "../../store-assets/myeffect.png",
  "description": "Short line shown in the installer."
}
```
`source` is the plugin folder that contains `manifest.json`, relative to `publish/`. Then run the publish command.

### Updating the installer app itself
1. Edit `app/` and bump `AppVersion` in `app/GlowFXInstaller.cs`.
2. Run `node publish/publish.js --installer --push -m "Installer 1.0.1"`.

Open copies show a banner, **Update now**, which swaps in the new `.exe` and restarts.

### Testing before you push
```
node publish/publish.js
installer\GlowFXInstaller.exe --catalog "%CD%\catalog.json"
```
This runs the app against your local files instead of GitHub.

## How it works
- `catalog.json` lists each plugin's id, version, package (`.ccx`), SHA-256 checksum and icon. Paths are relative, so the same catalog works from GitHub or a local folder.
- The app compares the catalog with what Photoshop has installed (`%APPDATA%\Adobe\UXP\PluginsInfo\v1\PS.json`).
- It downloads the package and verifies the checksum. When updating, it removes the old version first, then installs through Adobe's own installer (`UnifiedPluginInstallerAgent.exe`). Removing first stops Photoshop from keeping two versions.
- If Photoshop is open, it asks you to close it first, so the old version is removed cleanly.
- Log file for troubleshooting: `%LOCALAPPDATA%\GlowFX\installer.log`.

## Repo layout
| Path | What |
|---|---|
| `catalog.json` | What the app reads (generated by the publish script) |
| `plugins/<name>/` | Latest `.ccx` package and icon for each plugin |
| `installer/GlowFXInstaller.exe` | The app users download |
| `app/` | App source (C#/WPF). `app/build.ps1` builds it with the compiler that ships with Windows |
| `publish/` | Publish script and plugin list |
